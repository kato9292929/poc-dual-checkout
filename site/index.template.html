トークンの発行と呼び出し（TypeScript、@nevermined-io/payments）

import { Payments } from "@nevermined-io/payments";

const payments = Payments.getInstance({ nvmApiKey: process.env.NVM_API_KEY, environment: "{{nvm_env}}" });
const { accessToken } = await payments.x402.getX402AccessToken("{{plan_id}}", "{{agent_id}}", {
  scheme: "nvm:card-delegation",
  delegationConfig: { delegationId: process.env.NVM_DELEGATION_ID },
});
const res = await fetch("{{first_card_url}}", {
  headers: { "payment-signature": accessToken },
});

ヘッダなしで呼ぶと HTTP 402 と PAYMENT-REQUIRED ヘッダ（Nevermined のプラン情報）が返ります。クレジットが足りないときも 402（insufficient_credits）で、課金はされません。
